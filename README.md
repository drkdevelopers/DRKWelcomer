# 👋 DRKWelcomer

A lightweight and customizable welcome plugin for **Bukkit**, **Spigot**, **Paper**, and **Purpur** servers.

Welcome your players with fully configurable join messages while keeping your server lightweight and easy to manage.

---

## ✨ Features

* 👋 Custom welcome messages
* 🎉 First join welcome messages
* ⚙️ Fully configurable messages
* 🎨 Color code support
* ⚡ Lightweight & optimized
* 🔄 Configuration reload command
* 🔑 Permission support
* 🛠️ Simple installation and setup

## 📥 Installation

1. Download the latest release from GitHub or Modrinth.
2. Place `DRKWelcomer.jar` into your server's `plugins` folder.
3. Restart your server.
4. Edit `config.yml` to customize your welcome messages.
5. Reload the configuration using `/drkwelcomer reload` or restart your server.

---

## 📜 Commands

| Command               | Description                      |
| --------------------- | -------------------------------- |
| `/drkwelcomer reload` | Reloads the plugin configuration |

---

## 🔑 Permissions

| Permission            | Description                               |
| --------------------- | ----------------------------------------- |
| `drkwelcomer.admin`   | Grants access to all DRKWelcomer commands |
| `drkwelcomer.reload`  | Allows reloading the configuration        |
| `drkwelcomer.welcome` | Allows managing welcome features          |
| `drkwelcomer.bypass`  | Bypass welcome restrictions               |

---

## 📁 Configuration

DRKWelcomer includes easy-to-edit configuration files:

* `config.yml`
* `messages.yml`

Customize welcome messages, first-join messages, colors, and more to match your server.
